    - Offline annotation and training, onlin contour extraction.
    - Annotation: label is assigned to every pixel in the SEM image
    - Training: Fully Convolutional Network is used

Experiment:
    - Performance used contour extraction ratio: evaluates image wise contour extraction
        First,  thinning  image  processing is 
        done to contours in a segmented image and an annotation datum. Then, each contour in a segmented image is compared 
        manually  to  corresponding  contour  in  the  annotation  datum.  If  there  is  any  false  negative  concatenated  more  than  3 
        pixels or false positive concatenated more than 10 pixels, the contour is NG. If there is any NG contour, the segmented 
        image is NG, otherwise OK. Contour extraction ratio is calculated by percentage of OK to amount of segmented images.

    Generating synthetic SEM images to train a more robust model relying on Monte Carlo simulations
    They use a conditional GAN to generate synthetic images
Method:
    Artificially adding efects on the input contours and generating corresponding SEM images conditioned on these modified contours
    1. Defective contour extraction: real contour extraction from SEM images using model
    2. Image gen model training: train model to learn the mapping between defectiev contours and SEM images
    3. Defect introduction: controlled defects introduced into ideal contour images
    4. Synthetic SEM generation: generate synthetic SEM images based on the defective contour images
    5. Contour extraction model training: generated images paried with orignal ideal contours
Results:
    360 image dataset
    Clear improvement on contour closire over previous model without the data augmentaiton pipeline
    Open-line end defects
